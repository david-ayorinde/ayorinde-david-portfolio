# Ayorinde David Gbemiro — Portfolio

A responsive personal developer portfolio built with React and Vite.

## Requirements
- Node.js (LTS recommended)
- npm
- Visual Studio Code (recommended)

## Run locally
1. Extract this folder.
2. Open the `ayorinde-david-portfolio` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed in the terminal (usually `http://localhost:5173`).

## Create a production build

```bash
npm run build
npm run preview
```

The production files will be generated in the `dist` folder.

## Personalize before publishing
- Check the education wording and project descriptions for accuracy.
- Add your real GitHub and LinkedIn profile URLs when ready.
- Add screenshots and live links for projects that are deployed.
- You can add a profile photograph in `src/App.jsx` and style it in `src/styles.css`.
- Keep private credentials and `.env` files out of this frontend portfolio.

## Deploy
This is a standard Vite app and can be deployed to Vercel, Netlify or GitHub Pages. For Vercel, import the project repository and use the default Vite build settings:
- Build command: `npm run build`
- Output directory: `dist`
